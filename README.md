# Lista de Exercícios: Variáveis e Tipos de Dados em Java

Repositório acadêmico destinado ao armazenamento e organização de exercícios práticos desenvolvidos para a disciplina de programação em Java da **UNISUL**, sob a supervisão do professor **Osmar**.

O objetivo deste projeto é consolidar o aprendizado sobre a declaração de variáveis, tipos primitivos, manipulação de dados e operadores na linguagem Java.

## Tecnologias e Requisitos

- **Linguagem:** Java (JDK 11 ou superior)
- **Ambiente de Desenvolvimento:** Qualquer IDE compatível com Java (Eclipse, IntelliJ IDEA, NetBeans) ou editor de texto com terminal.

## Tópicos Abordados

Os algoritmos presentes neste diretório cobrem os seguintes conceitos fundamentais:

- Declaração e inicialização de variáveis
- Tipos de dados primitivos (`int`, `double`, `float`, `boolean`, `char`, etc.)
- Entrada e saída de dados no console (`Scanner`, `System.out.print`)
- Operadores aritméticos (`+`, `-`, `*`, `/`, `%`)
- Operadores de atribuição e incremento/decremento (`+=`, `-=`, `++`, `--`)
- Conversão e coerção de tipos (*Casting*)

## Instruções de Compilação e Execução

Para executar os códigos através da linha de comando, siga os passos abaixo:

1. Abra o terminal no diretório raiz onde o arquivo `.java` está localizado.
2. Compile o código-fonte utilizando o comando:
   ```bash
   javac ExercicioVariaveis.java
   ```
3. Execute o programa compilado com o comando:
   ```bash
   java ExercicioVariaveis
   ```
